# Brand, info pages, SEO and install · Implementation Plan

**Goal:** TripWise gets one identity everywhere (logo, slogan, icons, share image, splash), the pages a public
site needs (About, Privacy, Terms, Contact), and pages that search engines and link previews can read.

**Decided by the owner (2026-11-25):**
- Logo: the "Dwar" gateway (arch, sun on the horizon, ground) with the "Pagdandi" winding footpath leading in.
- Slogan: **Wander wisely** · **विवेक से यात्रा**. "शुभ यात्रा" stays as the footer sign-off.
- Contact email for now: devkingcric@gmail.com (to be replaced later).

## Global Constraints
- Comment everything; no AI credit; commit to `main`; push only on the owner's word.
- Zero cost: no paid services; no new runtime dependencies unless unavoidable.
- Brand colours: indigo `#1e2747`, paper `#f6efe3`, saffron `#e8813a`; fonts Fraunces (display),
  Plus Jakarta Sans (body), Tiro Devanagari Hindi.
- The mark is drawn in `currentColor` (indigo on light, paper on dark) with a fixed saffron sun.

## Tasks
1. **Identity** — `BrandMark` component; `Logo` uses it with the wordmark; slogan in footer and landing;
   `favicon.svg` (light/dark aware); PNG icons (192, 512, maskable 512, apple-touch 180) and a 1200×630
   share image, generated by `frontend/scripts/brand-assets.mjs` (Playwright, already a dev dependency).
2. **Info pages** — `/about`, `/privacy`, `/terms`, `/contact`; footer links; sign-up says it agrees to
   Terms and Privacy. Privacy covers what is actually stored (account, trips, Toli data, location sharing
   only while on, photos, AI providers, cookies/local storage, deletion).
3. **SEO** — per-page description, canonical and share tags (`Seo` component); `robots.txt`;
   `sitemap.xml` and a ready-made HTML page per public route (landing, explore, info pages, every
   destination with its guide text) written at build time from the catalogue, so crawlers and link
   previews see real content; JSON-LD for destinations.
4. **Install + splash** — web manifest, theme colours, icons; a branded splash shown until the app starts.

## Review Focus
1. Dark mode: the mark must stay visible (currentColor) and the favicon must switch.
2. Built pages must not break the app: React replaces the ready-made content on start.
3. Every destination in the catalogue appears in the sitemap and has its own built page.
4. Privacy text must match what the app really does (no promises it doesn't keep).
5. Phone widths (390 px): footer links and info pages without horizontal scroll.
