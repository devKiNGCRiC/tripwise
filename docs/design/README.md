# Design previews

Standalone HTML pages used to explore and agree on TripWise's look before building it.
Open any file directly in a browser.

| File | What it is | Status |
| --- | --- | --- |
| `tripwise-monsoon-editorial.html` | Homepage in the **Monsoon Editorial** style: living liquid colour, frosted glass, serif headlines with Hindi accents, a self-drawing rangoli and cinematic photo journeys. Day (dawn) and Night (monsoon) themes. | **Chosen** direction for the UI rewrite |
| `tripwise-moods.html` | Mood page comparing three directions: A Clay Chhatri, B Liquid Monsoon, C Rangoli Editorial. B and C were combined into Monsoon Editorial. | Exploration |
| `descent-world-prototype.html` | The Descent: 3D sky-to-land scenery prototype. | Superseded |
| `descent-photo-pack-preview.html` | The Descent: photo version of the scenery. | Superseded |
| `yatra-mela-preview.html` | Yatra Mela: departure-board and truck-art style. | Superseded |
